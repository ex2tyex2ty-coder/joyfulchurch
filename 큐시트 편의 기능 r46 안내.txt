r46 · 공개 큐시트 검색 / 큰 글씨 / 인쇄·오프라인 저장

추가 기능
1. 큐시트 → 전체 큐시트에서 순서명·찬양 제목·성경 구절 표기·시간을 검색합니다.
   ‘찬양’과 ‘말씀’으로 좁혀 볼 수 있습니다. 여러 검색어를 넣으면 모두 포함하는
   항목을 찾습니다. 성경 전체 본문 검색이 아니라 큐시트에 적힌 내용 검색입니다.
   검색 결과 버튼을 누르면 ‘한 순서씩 보기’에서 해당 순서가 열립니다.
   검색 후에도 번호는 원래 큐시트 순서를 유지합니다.
2. ‘큰 글씨 보기’를 켜면 찬양 목록·전체 순서표·본문 말씀을 크게 표시합니다.
   선택한 순서는 유지됩니다. 브라우저의 개인 보기이며 다른 사람에게 영향 없습니다.
3. ‘인쇄·오프라인 저장’을 열고 공개 큐시트를 HTML 파일로 내려받습니다.
   현재 검색 조건과 무관하게 선택한 예배의 전체 공개 순서를 저장합니다.
   본문 말씀 포함 여부를 선택할 수 있고, 본문은 최대 100절까지 포함합니다.
   저장 파일을 브라우저에서 열면 인터넷 없이 읽고 인쇄/PDF 저장할 수 있습니다.
   휴대폰에서는 다운로드/파일 앱에 저장되며, 인쇄는 기기의 공유 메뉴를 사용할 수도 있습니다.
   저장 파일은 자동 갱신되지 않고, 실시간 알림이나 공동 진행은 포함하지 않습니다.
   팀 내부 메모·담당자·음향/조명 지시는 공개 파일에 넣지 않습니다.

업로드 전 주의
- 행사·매뉴얼 수정·운영 기록을 사용했다면 기존 사이트에서 관리자 로그인 →
  데이터·백업 → 데이터 내보내기 → 내보내기 파일 생성 → SQLite 복구용 백업을
  먼저 본인 컴퓨터로 내려받으세요. 생성만 해두지 말고 반드시 다운로드하세요.
- ZIP을 풀고 내부 파일·폴더를 기존 app.py와 같은 위치에 업로드한 뒤 Streamlit Reboot.
- 기존 Secrets, 데이터, Google 원본을 삭제하지 마세요. 새 Secrets는 필요 없습니다.
- 적용 후 버전 표시가 2026.09.18-r46인지 확인하고 큐시트에서 기능을 확인하세요.

비용 및 미포함 사항
- 새 외부 유료 서비스, 요금제 변경, DB 이전·삭제를 실행하지 않았습니다.
- 이 기능을 위해 새 계정이나 유료 API가 필요하지 않습니다.
- 로컬 SQLite 데이터의 영구 저장소 이전은 아직 보류 상태입니다.
- 주보는 원본이 제공되지 않아 미등록 안내 상태입니다.
- 실제 iPhone Safari의 저장·인쇄 동작은 기기에서 최종 확인이 필요합니다.
