r45 · 큐시트 안정성 / 권한 / 다른 메뉴 무음 알림

중요: 이번 버전은 운영 데이터 영구 저장 이전을 포함하지 않습니다.
Supabase 요금제 변경, 유료 전환, 운영 데이터 이전·삭제는 실행하지 않았습니다.
주보는 실제 원본이 없어 여전히 미등록 안내 상태입니다.

업데이트 전
- 행사·매뉴얼 수정·운영 기록을 사용했다면 기존 사이트에서 관리자 로그인 →
  데이터·백업 → 데이터 내보내기 → 내보내기 파일 생성 → SQLite 복구용 백업을
  먼저 본인 컴퓨터에 내려받으세요. JSON/CSV도 함께 보관하면 좋습니다.
- 파일을 생성만 해두는 것은 서버 밖 백업이 아닙니다. 반드시 다운로드하세요.
- ZIP 내부 파일·폴더를 기존 app.py 위치에 업로드한 뒤 Streamlit Reboot.
- 기존 데이터, Secrets, Google 원본은 삭제하지 마세요.

수정 사항
1. 공개 큐시트 갱신 실패 시 이 브라우저 세션의 마지막 정상본을 계속 표시합니다.
   보관 시각과 연결 실패를 안내하며, 화면 재실행 시 재시도는 30초 간격으로 제한합니다.
   최신 큐시트 다시 읽기로 즉시 재시도할 수 있습니다.
   처음 방문했거나 브라우저 세션이 초기화된 상태에서는 보관본이 없을 수 있습니다.
2. 개인 위치와 선택 예배를 목록 번호 대신 ID로 기억합니다.
   원본에 항목/날짜가 추가돼도 선택을 유지하고, 삭제·이름 변경 시 안내합니다.
3. 담당 공란인 별도 순서가 앞 본문에 합쳐지는 오류를 수정했습니다.
   실제 원본의 시간 수식이 채워진 본문·따옴표 찬양 제목 행도 이어서 읽습니다.
   자유로운 원본 형식 모두를 지원하는 것은 아니므로 날짜와 내용을 확인하세요.
4. 해결·보관, 반복 발생, 운영 기준 확정 직전에 팀 권한을 재검증합니다.
   열린 창에서 로그인 시간이 만료되면 저장되지 않습니다.
5. 로그인 중에도 접근번호를 다시 입력해 1시간 연장할 수 있습니다.
   담당자 예배 진행 화면은 만료 10분 이내에 안내합니다. 무인 자동 연장은 아닙니다.
6. 음향석 로그인 → 수신 방 선택 → ‘다른 메뉴에서도 무음 알림 받기’를 켜면
   큐시트·주보·팀 게시판에서도 선택한 방의 새 요청 팝업을 받을 수 있습니다.
   기본은 꺼짐입니다. 켰을 때 해당 음향석 세션에서 약 5초마다 DB를 읽습니다.
   기존 음향 요청 화면의 실시간 방식은 그대로 유지합니다.
   일반 열람자는 이 감시 기능으로 음향 DB를 읽지 않습니다.
   브라우저 종료·절전·화면 잠금에서 수신을 보장하는 OS 알림은 아닙니다.
7. 한국 날짜 기준으로 큐시트를 판정하고 ‘팀 게시판’ 명칭을 통일했습니다.
   관리자 전용 메뉴는 전체 메뉴에서도 관리자에게만 표시합니다.

남은 작업
- 로컬 SQLite 기반 행사·매뉴얼·운영 기록을 영구 저장소로 옮기는 작업은 보류.
  비용/사용량 확인과 백업 후 별도로 진행해야 합니다.
- 실제 iPhone Safari, 운영 PostgreSQL 다중 기기 수신은 배포 후 리허설 필요.
- 새 Secrets는 필요 없습니다. 기존 AUDIO_DATABASE_URL과 음향석 로그인을 사용합니다.
