r39 · 음향석 전용 예배방 삭제

음향석 로그인 → 수신할 예배방 선택 → 예배방 삭제 펼치기
→ 삭제할 방과 안내 확인 → 동의 체크 → 이 예배방 삭제

종료 버튼을 삭제 버튼으로 교체했습니다.
해당 방의 참여 정보, 요청, 답변, 보관된 대화를 영구 삭제합니다.
복구할 수 없습니다. 다른 예배방과 팀 확인 게시판은 건드리지 않습니다.
참여자 화면에는 삭제 버튼이 없고, 삭제 시 음향석 로그인 유효기간을 다시 검사합니다.
12시간이 지나 자동 종료된 방도 음향석에서 선택해 삭제할 수 있습니다.
대화만 잠시 숨기려면 기존 대화 보관 기능을 사용하세요.
