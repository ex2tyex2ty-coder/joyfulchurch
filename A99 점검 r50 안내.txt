r50 · A99 진단 보강 및 PostgreSQL 메시지 전송 오류 수정

확인된 수정
- 추가 메시지 전송 쿼리의 LIKE 패턴을 매개변수로 전달하도록 수정했습니다.
  기존 코드의 % 문자가 PostgreSQL 드라이버에서 잘못 해석되어 A99가 발생하는 것을 재현했습니다.
- 실제 PostgreSQL 드라이버의 쿼리 변환기로 검증했습니다. 운영 DB에 접속하거나 데이터를 변경하지 않았습니다.

진입 즉시 A99가 발생하는 경우
- 위 전송 쿼리는 메시지를 보낼 때만 실행되므로 초기 진입 오류의 원인으로 단정할 수 없습니다.
- 오류에 준비 단계, 허용된 예외 유형, SQLSTATE(있는 경우)를 표시합니다.
  원본 드라이버 메시지, 접속 주소, 비밀번호, SQL 매개변수는 표시하지 않습니다.
- 초기 연결 실패 화면에 실행 버전도 표시합니다.
- 전달받은 캡처는 ‘전체 메뉴 / 예배 도움 요청’의 이전 화면이었습니다.
  r49 이후 화면은 ‘음향 요청 / 큐시트 / 더보기’와 역할 선택 버튼입니다.

적용·확인
1. 기존 로컬 운영 데이터를 백업하세요.
2. ZIP 내부 전체 파일·폴더를 기존 app.py와 같은 위치에 업로드하세요. requirements.txt도 포함합니다.
3. Streamlit 앱이 연결된 저장소·브랜치·실행 파일 경로가 업로드한 위치와 같은지 확인하세요.
4. Reboot 후 새로고침하고 버전 2026.09.29-r50을 확인하세요.
5. 여전히 실패하면 오류 코드와 괄호 안 ‘단계 / 진단’을 포함한 화면만 공유해 주세요.
   비밀번호나 Secrets는 공유하거나 삭제하지 마세요.

r49 메뉴 개편, 큐시트 시간 열 제거, r48 대화 입력창 유지가 모두 포함된 전체 업로드본입니다.
