JOYFUL WORSHIP OPS — GitHub 업로드 안내

1. GitHub의 ex2tyex2ty-coder/joyfulchurch 저장소를 엽니다.
2. 상단 Add file → Upload files를 누릅니다.
3. 이 폴더 안의 파일과 .streamlit, data 폴더를 모두 끌어다 놓습니다.
4. 화면 아래 Commit changes를 누릅니다.
5. Streamlit Cloud에서 자동 재배포가 시작되면 완료될 때까지 기다립니다.

Streamlit 배포 설정
- Repository: ex2tyex2ty-coder/joyfulchurch
- Branch: main
- Main file path: app.py
- App URL: https://joyfulchurch.streamlit.app/

중요
- data 폴더의 joyful_worship_ops.db는 앱 초기 데이터를 담고 있으므로 함께 올립니다.
- 2026.08.13-r20 예배 인원 구조 변경 시 app.py, db.py, migration.py, config.py와 data/joyful_worship_ops.db를 반드시 같은 배포에서 함께 올립니다.

- 이 안내 파일은 앱 실행에 필요하지 않지만 함께 올려도 안전합니다.
