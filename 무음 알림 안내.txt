r40 · 음향석 큰 무음 알림

음향석 로그인 후 수신할 예배방을 선택하세요.
새 요청이 수신되면 화면 중앙에 요청자와 내용을 크게 표시합니다.
여러 요청은 한 알림창에 모이며 ‘알림 확인 · 닫기’를 누를 때까지 유지합니다.
알림 확인은 처리 중/완료 상태를 바꾸지 않습니다. 대화에서 별도로 처리하세요.
‘무음 알림 테스트’로 표시를 확인할 수 있습니다. 소리·진동은 발생하지 않습니다.
처음 입장할 때 남아 있는 확인 대기 요청도 알려 줍니다.
같은 접속 세션에서는 확인한 요청을 반복 알리지 않습니다.
브라우저 전체 새로고침/재접속으로 세션이 초기화되면 대기 요청이 다시 뜰 수 있습니다.

현재 선택한 방의 음향석 화면을 열어 둬야 보입니다.
다른 프로그램 위로 뜨는 운영체제 알림은 아닙니다.
화면 잠금·절전·백그라운드 탭에서는 수신/표시가 지연될 수 있습니다.
자동 수신에는 기존 Supabase 실시간 연결이 필요합니다.
연결이 없거나 끊기면 화면 안내에 따라 재연결 또는 요청·답변 새로고침을 하세요.
이미 실시간 연결을 사용 중이면 Secrets 변경은 필요 없습니다.

ZIP 내부 파일·폴더 전체를 기존 GitHub app.py 위치에 업로드하고
Streamlit에서 Reboot 하세요. 실제 사이트의 실시간 수신은 두 기기로 확인하세요.
