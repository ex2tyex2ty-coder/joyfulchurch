r49 · 음향 요청 중심 메뉴 / 큐시트 시간 표시 제거

- 첫 화면: 싱어·연주자 / 키즈룸 / 음향석 큰 선택 버튼.
- 주요 메뉴: 음향 요청 / 큐시트 / 더보기. 모바일은 하단 고정, PC는 상단 표시.
  글을 입력하는 동안은 모바일 키보드와 겹치지 않도록 고정 배치를 해제합니다.
- 주보, 팀 게시판, 행사, 관리 기능은 더보기에서 접근합니다. 공개 자료는 로그인 없이 이용합니다.
- 같은 브라우저의 사용 화면과 개인 대화 자동 복귀를 지원합니다. 브라우저 저장 차단 시 복귀코드를 사용하세요.
  사용 화면을 기억하는 것은 인증이 아닙니다. 음향석 접근번호 확인은 그대로 유지합니다.
- 음향석은 미처리 우선 대화 목록에서 한 사람을 선택해 답변합니다.
  다른 사람의 새 메시지가 와도 선택한 대화를 강제로 바꾸지 않습니다. 새 메시지는 무음 팝업으로 알립니다.
- 완료·확인·보관 후에도 참여자 입력창은 유지합니다. 보관·담당 해제는 대화 정리·보관에 모았습니다.
- 큐시트 옆 시간 열을 화면과 공개 인쇄·저장본에서 제거했습니다.
  찬양 제목(예: 시간을 뚫고), 본문, 순서는 유지하며 구글 원본은 변경하지 않았습니다.
- 음향석의 ‘키즈룸·찬양팀 입장 QR 만들기’에 실제 배포 주소를 입력하면 전용 QR을 저장할 수 있습니다.
  외부 QR 서비스 없이 생성합니다. QR에 개인 복귀코드·접근번호를 넣지 않으며 예배방 확인은 유지합니다.

적용 방법
1. 관리자 데이터·백업에서 기존 로컬 데이터를 백업합니다.
2. ZIP을 풀어 내부 파일과 폴더 전체를 기존 app.py와 같은 위치에 업로드합니다.
3. requirements.txt도 포함하세요. QR 생성용 qrcode가 추가되었습니다.
4. Streamlit에서 Reboot 후 기존 열린 탭을 새로고침합니다.
5. 화면 하단 버전 2026.09.28-r49를 확인합니다. 기존 데이터와 Secrets는 삭제하지 마세요.

검증 범위
로컬 자동 테스트, 모의 실시간 통신을 사용한 키즈룸↔음향석 반복 대화,
모바일 크기 브라우저에서 메뉴 이동·자동 복귀·큐시트 표시를 검증합니다.
운영 Supabase·교회 네트워크·실제 iPhone Safari는 업로드 후 별도 확인이 필요합니다.
새 유료 서비스나 운영 DB 이전은 적용하지 않았습니다.
