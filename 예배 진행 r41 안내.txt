예배 진행 r41 · 주일/금요 큐시트 연결

포함: 날짜/영역별 불러오기, 뿌나+설교 후 찬양, 본문/인용구절 조회,
개인 터치 이동, 공동 진행, 담당별 보기, 준비 체크, 확정본/변경 승인,
무음 준비 요청, 음향방 연결, 인터넷 없이 볼 HTML 사본.

제외: 찬양 이력, 실제 진행시간 기록, 예배 후 메모/게시판 전달,
신규 봉사자 안내, 찬양/말씀 외부 공유, 장비 자동 제어와 자동 송출.

업로드
1. ZIP을 풀고 내부 파일·폴더를 기존 GitHub app.py와 같은 위치에 업로드합니다.
2. Streamlit에서 Reboot를 실행합니다. 기존 파일/데이터/Secrets는 삭제하지 마세요.
3. 기존 AUDIO_DATABASE_URL 저장소를 사용합니다. 새 Secrets는 필요 없습니다.
4. 서버가 cue_sessions 테이블과 음향 요청의 cue_context 필드를 추가합니다.
   기존 요청·답변은 보존합니다. 구글 원본에는 쓰지 않습니다.

시작
1. 팀원 로그인 또는 음향석 로그인 후 ‘예배 진행’ 메뉴를 엽니다.
2. ‘구글 큐시트 불러오기’에서 주일/금요 선택 → 큐시트 읽기를 누릅니다.
3. 날짜·탭·영역과 찬양/본문 미리보기를 확인하고 동의 후 엽니다.
   주일 원본은 한 탭에 여러 날짜가 나란히 있으므로 꼭 날짜를 확인하세요.
   현재 파일에 없는 다음 예배 날짜를 추측해 만들지 않습니다.
4. ‘내가 보기’에서는 이전/다음 또는 전체 순서의 항목을 눌러 이동합니다.
   개인 위치는 주소에 유지됩니다. 같은 주소로 새로고침하면 복귀합니다.
5. 본문 순서에서는 기존 bible_text.txt의 본문을 표시합니다.
   인용구절은 별도 입력/조회하며, 진행 담당자는 준비 목록을 공유할 수 있습니다.

공동 진행
1. 저장한 같은 예배를 각 팀원이 엽니다.
2. ‘내 담당·보기 방식·진행 권한 설정’에서 담당을 선택합니다.
3. 진행 담당 한 명이 ‘진행 담당 맡기’를 선택합니다.
   최초 생성자가 처음 진행 권한을 갖습니다. 담당 해제 후 인계할 수 있습니다.
   연결이 끊긴 담당은 최대 90초 뒤 다른 팀원이 인계할 수 있습니다.
4. 진행 담당 설정에서 예배용 확정 → 공동 진행 시작을 누릅니다.
5. ‘진행 따라가기’를 선택합니다. 진행 담당자의 이전/다음만 팀의 순서를 바꿉니다.
6. 전체 순서에서 임의 항목을 누르면 개인 보기로 전환됩니다.
   진행 담당자는 보고 있는 순서를 팀의 현재 순서로 별도 지정할 수 있습니다.
7. 화면을 연 동안 약 5초마다 DB를 조회합니다. 구글시트는 매번 읽지 않습니다.
   잠금/절전/백그라운드/연결 장애에서는 지연될 수 있습니다.
8. 팀 로그인 시간은 기존 설정을 따릅니다. 만료되면 다시 로그인해야 합니다.

준비·수정
- 원본 체크 사항을 팀원이 직접 확인합니다. 지난 예배 체크는 복사하지 않습니다.
- 진행 담당자는 이번 순서 메모에 악보/음원 주소나 준비 메모를 적을 수 있습니다.
- 구글 원본 변경은 ‘이 예배의 원본 변경 확인’ 후 비교·동의·승인해야 반영됩니다.
- 승인 시 준비 체크는 초기화합니다. 변경을 놓치지 않도록 다시 확인하세요.
- 현재 진행 순서가 삭제된 변경은 바로 반영하지 않습니다. 두 목록에 모두 있는
  순서로 이동한 뒤 변경을 반영하세요. 날짜/탭/영역이 달라지면 새로 불러옵니다.
- 한 절 보기/본문 복사와 HTML 사본을 사용할 수 있습니다.
  사본은 순서·본문·공유한 인용구절·메모를 포함한 내부 팀 자료입니다.
  브라우저에서 사본을 열어 인쇄할 수 있으며 실시간 동기화는 동작하지 않습니다.

알림·음향
- 진행 담당자는 담당별 무음 준비 요청을 보낼 수 있습니다.
- 수신자는 이 예배 진행 화면에서 자신의 담당을 선택해야 해당 요청이 보입니다.
- ‘전체’ 요청은 각 담당 구분별로 확인합니다. 한 담당의 확인은 같은 담당끼리 공유합니다.
- 음향방을 명시적으로 연결하고 공동 진행을 시작하면 새 음향 요청에 당시 순서 이름이 붙습니다.
- 실제 음향 요청과 답변은 기존 ‘음향 요청’ 화면에서 확인합니다.
  음향방 연결만으로 그 요청 팝업이 예배 진행 화면에 표시되지는 않습니다.
- 음향방을 삭제해도 저장한 큐시트는 유지되고 연결만 해제됩니다.

지원 범위/점검
- 알려진 날짜·내용·담당 표 형식, 탭별 앞 300행/60열, 파일당 최대 40탭.
- 본문/설교 후 찬양의 이어지는 행을 연결하고, 메들리의 + 표기는 유지합니다.
- 없는 키/악보/인용구절은 자동 생성하지 않습니다.
- 검증은 실제 두 구글파일 읽기 + 로컬 SQLite/화면 테스트 기준입니다.
  배포 후 두 기기로 공동 순서/준비 알림/음향방 연결을 최종 확인하세요.
